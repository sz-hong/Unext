# 新聞監看工作台 MVP

以 Edge 或 Chrome 開啟同資料夾的 `index.html` 即可使用。展示可離線操作，請保留同一資料夾內的程式與素材。

1. 首頁已載入四台一小時的合成批次，選中民視 12:38 的 N43 待確認格。
2. 查看合成的文字證據，可播放同台的 11/06 廣告包框原片節錄作為參考。
3. 按「預覽覆核差異」，套用示範修訂後查看 N43／N44 的異動，下載對應的 Excel。
4. 切到「廣告分析」，篩選民視，從 12:38:22 的破口返回證據。可用版本選單切回自動原始版。
5. 切到「議題分析」，選「捷運尖峰增班」，比較兩台的播出時間與起始分鐘收視。右表列出四個平台的示範瀏覽數。可從任一播出區段回查證據，或下載含兩個分頁的議題分析 Excel。
6. 「議題分析」每次呈現一種分析，預設顯示全部議題。從競台對照可跳至同分鐘的四台原片畫面。
7. 「四台畫面」提供 60 分鐘、每台各 60 張原片影格。拖動時間軸或按前後鍵，比較畫面、合成區段與示範收視；點選卡片按鈕回查該台的分鐘格。原片各取檔案位移 MM:15，未校正為電視播出時鐘。

兩個版本都是預備的展示資料。兩份 Excel 均改自官方乾淨範本，寫入 F／J／N／R 的目標格。11/06 影像的檔案位移獨立標示，合成的文字、時間及統計用於展示操作。
